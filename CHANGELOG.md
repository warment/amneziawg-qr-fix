# Changelog

## [1.2.0] - 2026-08-28

- Добавлена починка нераскрытых плейсхолдеров `$PRIMARY_DNS` / `$SECONDARY_DNS` (`--dns`).
- Добавлен патч `MTU` в `[Interface]` (`--mtu 1280`) для мобильных сетей.
- Добавлен флаг `--raw` для возврата конфига без модификаций.
- Ужесточены правила валидации: конфиги с нераскрытыми `$UPPERCASE_VARS` отклоняются, если не чинятся.
- Написан README.
- Инициирован CHANGELOG.

## [1.0.0] - 2026-05-08

- Первичный релиз: восстановление конфига AmneziaWG из `vpn://...` / `.vpn` в plain `.conf` + QR.

- Односимвольный ремонт битого base64url при неудачном декоде.
- Императивные правила валидации QR-полезной нагрузки.
- Интеграция как skill (`SKILL.md` + `agents/openai.yaml`).
